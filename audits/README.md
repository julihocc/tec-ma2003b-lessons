## 🎯 Purpose & Quality Standards

Audit documents in this directory track:
1. **Curricular Alignment:** Verification that every lesson covers 100% of its official Tecnológico de Monterrey syllabus subtopics.
2. **Mathematical Accuracy:** Review of derivations (OLS, MVN density, spectral decomposition, canonical correlations, MANOVA statistics).
3. **Reproducibility:** Ensuring all data generation scripts (`fetch_*.py`) produce deterministic outputs and all notebooks run cleanly from top to bottom.
4. **Typographic Consistency:** Ensuring uniform callout styles, color palettes, and notation standards across Typst notes and Touying slide decks.
