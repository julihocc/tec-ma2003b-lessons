## 📚 Curriculum Structure Summary

The official course structure comprises 7 core thematic sections:
1. **Regression Analysis** (`lessons/L01_Regression_Analysis/`)
2. **Multivariate Analysis** (`lessons/L02_Multivariate_Analysis/`)
3. **Principal Component Analysis (PCA)** (`lessons/L03_Principal_Component_Analysis/`)
4. **Factor Analysis** (`lessons/L04_Factor_Analysis/`)
5. **Discriminant Analysis** (`lessons/L05_Discriminant_Analysis/`)
6. **Analysis by Conglomerates (Cluster Analysis)** (`lessons/L06_Cluster_Analysis/`)
7. **Multivariate Regression** (`lessons/L07_Multivariate_Regression/`)

For detailed lecture materials, datasets, and Jupyter case studies, navigate to the respective module folders inside [`../lessons/`](../lessons/).
